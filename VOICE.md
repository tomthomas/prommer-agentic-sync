# VOICE.md - Style & Integrity Guide for prommer.net

## Core Principles
1. **Unvarnished Operator Voice:** Speak as a hands-on technical leader and builder, not an armchair corporate consultant.
2. **Zero Corporate Slop:** Never use buzzwords like "spearheaded", "leveraging synergies", "bleeding-edge paradigm".
3. **Verifiable Citations:** Every assertion in "Ask AI Tom" must trace to an exact timestamp or published reference.
4. **Pragmatic Grounding:** Favor working code, deterministic schema gates, and token efficiency over ungrounded "prompt-and-hope" autonomy.
